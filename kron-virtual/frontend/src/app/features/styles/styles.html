Index 0 — Static System Prefix

Affects KV Cache

Placed once at the very top of the prompt (messages[0]) alongside the Character and Persona. Local engines (llama.cpp, vLLM) cache these tokens across turns for fast responses. Editing Index 0 items mid-session invalidates the prefix KV cache and triggers a full prompt re-evaluation on the next turn — set these at session start and avoid changing them often.

High-level narrative rules: POV, tense, boundaries, and voice guidelines. Supports {{char}} and {{user}} placeholders. Example: "Write in third-person limited, past tense. Stay strictly in character as {{char}}. Never narrate {{user}}'s actions or thoughts."

Usually left blank so each Character's own default scenario is used. Fill this in only if this style enforces a specific framing or shared setting across characters.

Depth 1 — Dynamic Per-Turn Steering

KV-Cache Safe

Injected inline right before your latest user message (not as a second system message). Because LLMs attend most strongly to the end of the context, Depth 1 has strong influence over the immediate reply — and changing these mid-session does NOT invalidate your cached Index 0 prefix or earlier turns.

Active mood, tension, location shift, or immediate plot constraint for the next reply. Example: "Tone: tense, rain-soaked, suspicious. Keep the conversation focused on the missing ledger."

Short 1–2 line prose-rhythm anchor to prevent long-thread style drift. Phrase positively ("Write crisp dialogue with brief physical beats") rather than long "Do NOT..." ban lists, which often trigger the exact clichés you forbid.

Sent as an ephemeral Depth-0 turn when you click Suggest / Expand in the chat composer, keeping your Index 0 and conversation KV cache intact. Supports {{user}} and {{char}} placeholders.

Inference Samplers

KV-Cache Safe

Control how the model picks the next token during generation. Adjusting samplers never invalidates the KV cache and takes effect immediately on the next reply or Regenerate.

Controls creativity vs. predictability. Lower (0.6–0.75) is grounded and focused; higher (0.85–1.05) gives more varied phrasing and surprising turns.

Limits sampling to the smallest token set whose combined probability reaches P. Keep around 0.92–0.98 when pairing with Min P.

Dynamically trims unlikely garbage tokens relative to the top choice. 0.05–0.10 is the local RP sweet spot — lets higher temperatures stay coherent.

Hard ceiling on reply length per turn. Leave blank to let the server decide, or set e.g. 250–400 to enforce shorter, snappier replies.

"Don't Repeat Yourself" sampler: penalizes repeated multi-word phrases across the conversation without hurting grammar. Try 0.6–0.9 (0 or blank disables).
